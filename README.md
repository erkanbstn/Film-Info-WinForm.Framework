# Film bilgisi

Film kayıtlarını listeleyen masaüstü uygulaması.

## Ne var

Ekranlar `FilmProject` içindedir.

## Çalıştırma

Çözümü Visual Studio ile açıp başlangıç projesini çalıştırın. Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET Framework, Windows Forms ve ADO.NET.
